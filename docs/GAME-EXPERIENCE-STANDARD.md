# PLAY100 Game Experience Standard

PLAY100의 각 게임은 제목만 다른 미니게임이 아니라, 제목을 보는 순간 기대한 세계와 행동이 실제 플레이에 나타나야 합니다.

## 1. Title promise

제목은 다음 세 가지를 동시에 약속합니다.

1. **장소 또는 세계** — 항구, 철도, 정원, 우주 정거장처럼 화면에서 바로 읽혀야 합니다.
2. **플레이어 역할** — 관제사, 탐정, 정비사, 배달원처럼 무엇을 하는 사람인지 보여야 합니다.
3. **핵심 사건** — 구조, 분류, 운송, 추리, 방어처럼 플레이의 목적이 제목과 이어져야 합니다.

제목과 무관한 추상 도형에 테마 색만 입히는 방식은 허용하지 않습니다.

## 2. Material authenticity

출시 가능한 게임은 제목에 고유한 사물과 정보 표현을 최소 8개 포함합니다.

예를 들어 Arrow Harbor에는 화물선, 신호 부표, 암초, 부두, 등대, 조수 정보, 화물 명세, 항만 무전이 들어갑니다. 일반적인 사각형·별·코인만으로 세계를 대체하지 않습니다.

## 3. Mechanics belong to the world

핵심 조작은 세계 속 행동으로 설명할 수 있어야 합니다.

- 타일 회전 → 신호 부표 회전
- 실행 → 출항 명령
- 힌트 → 등대 탐조등
- 결과 화면 → 입항 또는 회수 보고서

UI 용어, 버튼, 실패와 성공 표현까지 같은 세계관을 유지합니다.

## 4. Environment progression

각 플레이 가능한 게임에는 최소 3개의 구별되는 환경 상태가 필요합니다.

- 장소 변화
- 시간대 변화
- 날씨 또는 조명 변화
- 위험도와 밀도 변화

단순 배경색 변경은 환경 변화로 계산하지 않습니다. 전경·중경·배경, 움직임, 주변 사물, 가시성 또는 게임 정보가 함께 달라져야 합니다.

## 5. Feedback and game feel

다음 중 최소 6개 이상의 명확한 피드백을 제공합니다.

- 선택 상태
- 오브젝트 반응
- 움직임과 관성
- 파티클 또는 흔적
- 충돌·실패 반응
- 성공 연출
- 점수·콤보 변화
- 환경음 또는 효과음
- 상황 메시지
- 카메라 흔들림·확대·조명 변화

## 6. First-minute fun

- 규칙 이해: 15초 이내
- 첫 성공 경험: 120초 이내
- 실패 후 재시작: 3초 이내
- 마우스와 터치 기본 지원
- 첫 화면에서 게임 플레이까지 최대 한 번의 클릭

## 7. Replay value

각 게임은 최소 3개의 재플레이 이유를 가집니다.

- 메달 또는 등급
- 최고 점수
- 더 적은 행동 수
- 콤보
- 일일 문제
- 스테이지 해금
- 수집·꾸미기
- 다른 환경이나 규칙

## 8. Automated quality gate

플레이 가능한 게임은 `games/<slug>/game.manifest.json`을 가져야 합니다. `npm run check`는 다음을 자동 검사합니다.

- 카탈로그와 id·slug·제목 일치
- 핵심 행동 3개 이상
- 제목 고유 소재 8개 이상
- 환경 3개 이상
- 피드백 6개 이상
- 마우스와 터치 지원
- 첫 성공과 재시작 기준
- 재플레이 동기 3개 이상

이 기준을 통과하지 못한 게임은 포털에서 `playable` 상태로 공개하지 않습니다.
