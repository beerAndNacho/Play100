## Production rule

- 대표작 20개: 진행·스킨·일일 도전까지 확장
- 일반 게임 40개: 3~10분 플레이와 레벨·점수 경쟁
- 실험 게임 40개: 30초~3분의 독특한 조작 검증
- 같은 게임의 색상 변경판을 별도 게임으로 계산하지 않음
- 첫 로딩 목표 20MB 이하, 가능한 경우 훨씬 작게 유지
- 모든 게임에 키보드 또는 터치 접근 경로 제공
- 서버가 필요한 기능은 실제 재방문 데이터가 확인된 게임에만 추가
